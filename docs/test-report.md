# 单元测试报告

运行命令：

```text
npm test
```

测试程序位于 `tests/domain.test.js`，使用 Node.js 内置 `assert`，没有引入额外依赖。当前共 13 个测试用例，覆盖以下场景：

1. 关键词规范化。
2. 按物品名称搜索。
3. 按地点和描述搜索。
4. 按寻物/招领类型筛选。
5. 按处理状态筛选。
6. 无匹配结果。
7. 必填项缺失校验。
8. 完整表单校验。
9. 新建信息默认值。
10. 更新目标信息状态。
11. 修改信息字段。
12. 时间格式化。
13. 首页统计数量。

测试结果：13/13 通过。

除单元测试外，浏览器手工检查了首页浏览、搜索、详情、联系提示、发布校验、发布成功、我的发布、修改、删除、状态更新和刷新后数据保留等流程。

## 结对复查清单

本分支由王伟浩复查发布页和“我的发布”模块，确认了以下结果：

- 空表单不能提交，缺失字段会显示中文提示。
- 发布成功后，新记录出现在“我的发布”，刷新后仍然存在。
- 状态下拉框可以切换为“已找到”或“已归还”，首页统计会同步更新。
- 修改后重新进入详情页，物品名称、地点和描述与修改结果一致。
- 搜索无结果时显示明确的空状态，不会出现空白页面。
